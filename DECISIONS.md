# Decisions

Each entry gives the decision and the reason.

1. **Database driver: Node's built-in `node:sqlite`.** It ships with Node 24, needs no native build on any OS, and supports FTS5 with the porter tokenizer (verified). So no WebAssembly fallback was needed.
2. **TypeScript 6.0.3, not 7.0.** typescript-eslint 8.72 (the latest) supports only `typescript <6.1`. The lint check is a hard requirement.
3. **Web stack: Hono server with a Vite and React client in one app.** It is lighter than a meta-framework, runs everything with one `pnpm start`, and keeps all model calls server-side.
4. **No per-package build.** Workspace packages export TypeScript source, run through tsx (server, CLI) and Vite (client). This means fewer moving parts on a clean machine.
5. **Anthropic adapter uses the official `@anthropic-ai/sdk`.** Other providers (OpenAI and OpenAI-compatible, Gemini, Ollama, Adaption) use `fetch` against their documented REST APIs. Adaption ships only a Python SDK.
6. **Adaption custom voice model is selected by id.** Adaption documents no endpoint that lists a user's trained models. The creator chooses from `GET /api/v1/models` or enters the id (`ADAPTION_VOICE_MODEL`). Kathix doesn't upload training data itself. It exports an `instruction`/`response` JSONL that maps onto Adaption's documented `column_mapping` (`prompt = instruction`, `completion = response`), so training calls that can't be checked without credentials never ship.
7. **Script editor: CodeMirror 6 over a plain-text script format.** It stays fast on 20,000-word scripts, gives precise cursor and range control for diffs and suggestions, and keeps character offsets exact for evidence and provenance.
8. **Standalone modes use a hidden "Scratchpad" project.** It persists work when no project is open and never appears on the shelf.
9. **Seed canon goes through a structured story-bible import path.** A code parser turns "Type: Name" blocks into proposals with verbatim spans. This lets `pnpm seed` work on a clean machine with no model provider. AI extraction from episodes stays the live import path shown in the demo.
10. **Default tier mapping from live model lists uses size hints in model ids** ("mini", "flash", "small" → fast; "pro", "large" → deep). It uses no hardcoded model names, and the creator can override it on the Model Router screen.
11. **A `platform` package and a `runtime` package beyond the brief's table.** Modules need a shared contract (types, edit helpers, SSE, errors) that must not live in a module. Both the server and the CLI need one assembly step. Keeping these separate avoids import cycles and keeps "one package plus one registry line" true.
12. **One registry file, `modules.config.json`.** The server and CLI import modules by path and the client discovers pages with `import.meta.glob`. Adding a module is one package and one line.
13. **Deterministic test provider in the template files.** Each prompt template carries its own rule-based `mock()` answer. The test provider (enabled only by `KATHIX_MOCK_PROVIDER=1`) uses it, so tests and evals exercise the real rendering, validation, evidence verification and UI without a network. It is never shown to users.
14. **Structured story-bible import.** `## Type: Name` sections with `- Key: value` lines are a real creator feature for people who already keep a bible, and it needs no model. The sample project's canon is loaded this way, so `pnpm seed` works offline.
15. **Evidence verification tolerates only whitespace, case and typographic quotes.** Models often normalise curly quotes and line breaks. Anything beyond that is treated as unverified and dropped.
16. **Controls are never greyed out.** A button whose form is incomplete stays clickable and says what it needs. This satisfies "no disabled control" without hiding forms.
17. **Deletes are delayed for an undo window.** Projects, scripts, canon entries, voice profiles and samples are hidden at once and deleted after 8 seconds unless the creator clicks Undo. Proposal rejections and "intentional" marks are undone through the server.
18. **Jobs start after the first capability probe.** A resumed Showrunner step otherwise ran before the probe and failed as "not available". Found by the restart test.
19. **Platform length limits are enforced in code.** The limits come from a table (`packages/modules/forge/src/limits.ts`) of hard platform limits, or visible-before-truncation lengths where no hard limit exists. Options over the limit are discarded and the model is asked once more. Kathix never shows an over-limit option, and never truncates one silently.
20. **The voice profile is a fixed feature set measured in code.** It covers sentence length and spread, point of view, punctuation rates, contractions, reading grade, MATTR vocabulary richness, short-sentence share and a 40-word function-word fingerprint. The match score is a weighted similarity. The model only writes the short qualitative description and line rewrites.
21. **Backgrounds mix photographs and procedural images.** CC0 photographs that met the bar (3840 pixels or wider, landscape, no people, no logos) were found for Canon Vault and Continuity Guard. The other slots use procedural masters in the same manifest, as the brief's fallback allows. The scrim was strengthened, and the muted text colour lifted, until the automated pixel test passed at 4.5:1 or better on every image.
22. **The UI truth test treats already-selected tabs and the current nav link as working.** They carry `aria-selected` or `aria-current`; clicking the page you are on has nothing to change. A native file chooser opening also counts as an effect.
23. **The Anthropic adapter sends no `temperature`.** The current API rejects it, so tier depth is mapped to `output_config.effort` instead. It is retried without effort for models that reject that field.
24. **Browser spellcheck turns off for scripts over 40,000 characters.** Measured on a 20,000-word script, Chromium's spellcheck re-scan pushed keystrokes to 500–600 ms. Without it they stay within 16–48 ms, inside the 50 ms budget. Normal-length scripts keep spellcheck. The editor also no longer copies the whole text on every keystroke, and selection state settles after 120 ms instead of re-rendering on every key.
